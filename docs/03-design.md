# 03. Design

| 선택 | 대안 | 근거 | 트레이드오프 |
|---|---|---|---|
| **1) 백엔드** — FastAPI | Django, Express | 가볍고 Pydantic 검증과 자동 문서가 기본으로 붙는다. 이 앱은 API 7개뿐이라 Django 의 관리자·인증 같은 큰 틀이 필요 없다. 팀 스택이 Python 으로 통일된다. | 인증·관리자 화면은 직접 만들거나 라이브러리를 붙여야 한다. 검증 실패 기본값이 422 라서 400 으로 바꾸는 핸들러를 직접 둬야 한다. |
| **2) 프론트** — Vanilla JS + Tailwind CDN. `index.html` 과 `app.js` 2개 파일만. 백엔드가 같은 오리진에서 제공하며 `file://` 로 직접 열지 않는다. | React, Vue | 화면이 4종뿐이라 빌드 도구와 프레임워크가 과하다. 같은 오리진이면 CORS 설정이 필요 없다. 실습에서 파일 2개로 전체 구조가 보인다. | 화면이 늘면 `app.js` 가 커지고 구조를 스스로 지켜야 한다. 컴포넌트 재사용·생태계 도구를 못 쓴다. |
| **3) DB** — SQLite (SQLAlchemy ORM, 추후 PostgreSQL 전환 고려) | PostgreSQL 즉시 도입 | 설치와 서버가 필요 없어 시작이 빠르다. ORM 을 거치면 나중에 DB 를 바꿀 때 쿼리 수정이 적다. | 동시 쓰기에 약하고 PostgreSQL 전용 기능을 못 쓴다. 전환 때 `AUTOINCREMENT` 같은 SQLite 특성을 점검해야 한다. |
| **4) CSS** — Tailwind 만. styled-components 금지 | styled-components, 직접 작성한 CSS | CDN 한 줄로 쓰고 클래스만으로 스타일을 끝낼 수 있다. 스타일 방식이 하나라 유지보수가 쉽다. | HTML 클래스가 길어진다. CDN 방식은 빌드 최적화(미사용 클래스 제거)를 못 받고 인터넷 연결이 필요하다. |
| **5) 받아쓰기** — Gemini API (`gemini-3.1-flash-lite`). 키는 `.env` 로만 읽고 저장소에 올리지 않는다. | Whisper 자체 구동, 브라우저 음성 인식 | 서버에 모델을 올리지 않아도 되고, 같은 API 로 세 갈래 구분까지 할 수 있다. 브라우저 음성 인식은 파일 업로드 입력에 맞지 않고 브라우저마다 다르다. | 외부 호출이라 네트워크·비용·장애 영향을 받는다 (실패 시 502, 구분 실패 시 빈 값 저장). 음성이 외부로 전송된다. |
| **6) 상태관리** — 모듈 변수 + DOM 직접 갱신 | 상태관리 라이브러리, 프레임워크 상태 | 상태가 목록·상세·테마 정도로 적다. 라이브러리 없이 `app.js` 한 파일에서 흐름이 보인다. | 화면이 복잡해지면 상태와 DOM 이 어긋나기 쉽다. 갱신 코드를 빠뜨리지 않도록 규칙이 필요하다. |
| **7) 디자인 시스템** — Mac OS UI 톤 (둥근 모서리, 부드러운 그림자, 반투명 카드, 시스템 폰트). 화면 배치와 요소 이름은 아래 규칙으로 정한다. | Material, Ant | 대상이 개발자가 아닌 실무자라 익숙하고 차분한 톤이 맞다. Tailwind 클래스만으로 구현할 수 있다. | 컴포넌트 라이브러리의 기성 부품을 못 쓰고 직접 만든다. 반투명 효과는 구형 브라우저에서 다르게 보일 수 있다. |
| **8) 테마** — 라이트/다크 토글, `localStorage` 에 저장, 초기값은 시스템 설정 | 라이트 고정, 서버에 저장 | 사용자가 고른 값이 새로고침해도 유지된다. 처음엔 시스템 설정을 따라 거부감이 적다. | `localStorage` 를 못 쓰는 환경에서는 값이 유지되지 않는다. 두 테마를 모두 확인해야 해서 화면 검수가 늘어난다. |

## 7) 화면 배치와 요소 이름

- 화면은 목록 · 넣기 · 상세 · 할 일 4종이다.
- 요소 이름(id)은 `docs/화면구성.pdf` 5쪽 id 표를 그대로 옮긴다.
- 화면 배치와 요소 이름은 이 절에 정해 둔다. 한 번 정하면 바꾸지 않고, 바꿔야 하면 사유를 먼저 적는다.

(현재 `docs/화면구성.pdf` 가 폴더에 없어 id 표는 비어 있다. PDF 가 들어오면 5쪽 표를 그대로 옮기고 이 안내 문구를 지운다.)
